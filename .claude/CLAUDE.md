# onec-python

Python-библиотека для описания конфигураций 1С:Предприятие кодом.
Генерирует XML-выгрузку конфигурации (иерархический формат) и загружает её
в информационную базу через пакетный режим Конфигуратора.

## Структура

- `src/onec/metadata/` — классы объектов метаданных (Catalog, Document, ...)
- `src/onec/types/` — типы реквизитов (String, Number, Ref, ...)
- `src/onec/query/` — язык запросов
- `src/onec/transpiler/` — транспиляция кода в BSL
- `src/onec/xml/` — генерация и разбор XML выгрузки
- `src/onec/platform/` — вызов 1cv8 / ibcmd
- `tests/golden/<версия платформы>/<случай>/` — эталонные выгрузки из настоящей 1С

## Команды

- Установка: `uv sync`
- Тесты: `uv run pytest -m "not platform"`
- Линтер: `uv run ruff check . && uv run ruff format .`
- Типы: `uv run mypy`

## Правила

- НИКОГДА не изменяй файлы в `tests/golden/`. Это эталоны из реальной 1С.
  Если тест не совпадает с эталоном, ошибка в генераторе, а не в эталоне.
- UUID существующих объектов при повторной генерации не должны меняться.
- Весь публичный API типизирован, mypy в строгом режиме.
- Имена объектов 1С в тестах и примерах — на русском, внутренний код — на английском.
- После изменения публичного API обнови README и раздел Unreleased в CHANGELOG.md.

## Формат выгрузки 1С

- Имена свойств в XML английские (CodeLength, Hierarchical), имена объектов — из конфигурации.
- Каждый новый объект нужно добавить в ChildObjects файла Configuration.xml.
- У каждого объекта есть порождаемые типы (CatalogRef, CatalogObject, ...) со своими TypeId и ValueId.
